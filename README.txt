FIVE MEN AND A FALLEN HEIRESS — WEBSITE

This is an original, lightweight HTML/CSS/JS website built from scratch.

FILES
- index.html = main page
- style.css = design and responsive/mobile styling
- script.js = editable content and navigation
- images/ = put your cover, character pictures, and gallery photos here later

CURRENTLY INCLUDED
- Title: Five Men and a Fallen Heiress
- Phone-style home screen with a live clock, story widget, and Maps / InstaPic / Calendar / Photos / Notes / Reminderz app icons
- Favorite-app dock and Home controls for returning from any section
- Maps locations and descriptions
- Exact InstaPic usernames and bios, including the verified badge for @AkohitoSaionji
- Blank Calendar
- Blank Photos section
- Notes section ready for future lore/content
- Reminderz app with the story's to-do list
- No music

EASY EDITING
Open script.js in a text editor.
- Edit the "locations" array to change/add Maps locations.
- Edit the "insta" array to change usernames/bios.
- Edit the "reminders" array to update the Reminderz to-do list.
- Later, photos can be connected in the avatar/gallery HTML.
- Calendar content can be added to the renderEmpty section or replaced with a custom calendar.

IMPORTANT
The website does not currently contain your uploaded images because they have not been provided in this build. Put them in the images folder when ready, then connect their filenames in script.js.

HOW TO USE
1. Unzip the folder.
2. Double-click index.html to preview it in a browser.
3. Upload the whole folder to your web host when ready.

PHONE LAYOUT
The page opens on the home screen. Tap an app icon to open a section, or use
Enter story to open Maps. Tap Home or the bottom home indicator to return.
On desktop, the site appears inside a phone frame. On mobile, it fills the
screen. App content scrolls inside the phone while navigation stays accessible.
